## C2 follow-ups (2026-10-09)

- **Duplicate-inscription race:** `POST /api/events/:id/subscribe` did check-then-insert, so N concurrent requests of one account created N paid orders (red: 5 of 8 requests returned 201 and 5 rows were written for the +595 account). Now `storage.createFreeSubscription` re-checks and inserts in one transaction holding `SELECT ... FOR UPDATE` on the event row (same pattern as `claimCourtesyRedeem`). Test: `duplicate free inscription race`. **Not covered yet:** `POST /api/orders` (pending orders, no dedupe at all by design) and `POST /api/courtesy/redeem` (check runs before the claim transaction; moving it inside is a small follow-up). **No unique index is possible:** prod already holds 7 (user_id, event_id) groups with more than one paid non-courtesy order (max 6), so the guard stays in application code.
- **Concurrent admin form saves:** `PATCH /api/admin/events/:id` takes `updated_at` and answers 409 when stale, with a conditional write. Tests: `admin event PATCH: optimistic concurrency (#7)` and `AdminEditEventPage.test.tsx` (sends `updated_at`, shows the 409 message). Attendee-count writes no longer bump `events.updated_at` (a sale is not an edit); other event writes (courtesy e-mail templates, certificate template) still do, and would make an open edit page answer 409 once.

## Round 2 (client), #6 completed (2026-10-09)

The first #6 fix only invalidated `/api/events/:id`. HomePage/EventsPage read `["/api/events"]` (`staleTime: Infinity`), the open free-subscribe dialog kept the event it captured, and `CourtesyRedeemPage` never refreshed its link, so those tabs kept getting 400. Now `refreshAfterStaleRegistration` also invalidates `["/api/events"]`, refetches the event and hands it to the dialog (`prompt.event` is replaced); the courtesy page invalidates `["/api/courtesy-links", code]`; the 409 "Atualize a página" counts as stale too. Tests: `hooks/useFreeSubscribe.test.tsx` > `list page with a form the admin changed` (red: `Unable to find a label with the text of: Pergunta nova`), `CourtesyRedeemPage.test.tsx` > `shows the question an admin added after the page loaded` (red: `Unable to find ... Turno preferido`), `eventRegistration.test.ts` > `flags the 409 reload message`.
